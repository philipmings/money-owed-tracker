MONEY OWED TRACKER - FINAL CLEAN V11

THIS IS A CLEAN RELEASE.

Display rules:
- Recent activity first line: Person Name · Category, BOTH bold.
- Categories are only: Loan, Purchases, Repayment, Adjustment, or a custom description for Other.
- No "Amazon for them".
- No "Bought for them".
- No "Purchase on behalf".
- No "I borrowed" / "They borrowed" labels.
- Date, invoice number, item details, currency and amount are regular weight.
- Existing Amazon transaction records display as Purchases.
- Existing purchase_on_behalf records display as Purchases.
- Existing loans display as Loan.
- Existing payments display as Repayment.
- Existing adjustments display as Adjustment.
- Detailed transaction notes are kept on the second line and are not deleted.

Data entry:
- They owe me: Loan / Purchases / Other
- They paid me: Repayment
- I owe them: Loan / Purchases / Other
- I paid them: Repayment

Exports continue to use the live Supabase PDF/Excel generator.

INSTALL:
1. Delete the old current app files from the GitHub repository.
2. Upload ONLY the files from this ZIP to the repository root.
3. Commit and wait for GitHub Pages to finish.
4. Open the site once with ?release=v11
5. Remove the old installed PWA from Samsung.
6. Install again from the refreshed Chrome page.
